# Code Puzzle Challenge

This folder is the self-contained 3x3 image puzzle module.

- `challenge.html` is the public puzzle page linked from the main site's `challenge.html`.
- `code-to-image.html` is the local helper for creating puzzle image assets.
- `weekly_challenge/` holds images used by the puzzle page.

Keep puzzle assets and helper files in this folder so future weekly challenges can be updated without spreading puzzle-specific files through the rest of the site.
